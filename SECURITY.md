# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No (Legacy Python) |

## Reporting a Vulnerability

If you discover a security vulnerability in Lyslyn, please report it responsibly by contacting the maintainers at security@lyslyn.org instead of opening a public issue.

Please include:
- A description of the vulnerability and its potential impact.
- Reproducible steps or a proof-of-concept `.lys` script.
- The operating system and architecture where the issue was observed.

We take security issues seriously and aim to acknowledge reports within 48 hours and provide a resolution promptly.
